# 重点收录 · Highlight Companion

把 Obsidian Markdown 课本里的高亮，持续收录到一篇重点笔记。保留章节和双向来源链接，将关键词归为重点，并生成可手动编辑的 Canvas 思维导图。

适用于 Obsidian 1.7.2 及以上版本。支持电脑、手机和 iPad，移动端已做界面适配。暂不支持 PDF。内容处理全部在本地完成，无需 API Key 或 AI 服务。

## 安装与更新

**使用 BRAT：** 安装并启用 BRAT，在添加测试插件入口输入 `KonkHsu/highlight-companion`，选择需要的版本安装。后续通过 BRAT 更新。

**手动安装：** 从 [Releases](https://github.com/KonkHsu/highlight-companion/releases) 下载 `main.js`、`manifest.json`、`styles.css`，放入仓库的 `.obsidian/plugins/highlight-companion/`，然后在 Obsidian 社区插件设置中启用「重点收录」。本插件尚未上架社区插件市场。

更新时替换这三个文件并重新启用插件，保留原有 `data.json`。手机和平板也需安装这三个文件。切换设备前等待笔记及插件数据同步完成，避免同时修改同一篇笔记。

## 高亮并收录

1. 在课本中选中关键词或句段，右键选择 **高亮并收录**。编辑视图也可执行同名命令。
2. 首次选择重点笔记。默认新建在 `重点笔记/课本名-重点.md`；也可选择已有笔记，插件会追加收录区。
3. 以后沿用绑定，自动追加到对应章节。执行 **收录当前课本已有高亮**，可以批量收录 `==高亮==`。
4. 点击原文的 **重点** 链接跳到条目，点击条目的 **返回原文** 回到来源段落。阅读视图直接点击；编辑视图按住 Cmd（Windows 为 Ctrl）点击。

单次选区限于一个正文段落或列表项。同一处高亮不会重复收录，不同位置的相同词分别保留。章节取自 Markdown 标题，标题前的内容归入「未分章节」。每篇重点笔记只绑定一本课本。

移动端在阅读或编辑视图长按选中文字后，拖动选区时隐藏操作区，松手并等待选区稳定后，在选区附近显示 **高亮并收录** 和 **撤销高亮并移除重点**。阅读视图会结合选区前后文字区分重复词，并兼容换行空白差异。如果选区跨越 Markdown 格式或仍无法唯一定位，请缩小到同一段内的普通正文文字，或切换编辑视图操作。

手机和 iPad 可在移动端工具栏添加 **高亮并收录** 和 **收录与整理面板**。在编辑视图长按选中文字后点击工具栏，或打开面板核对选词再收录。电脑可在「设置 → 快捷键」中搜索「重点收录」分配快捷键。

## 撤销与恢复

- **选词撤销：** 选中已收录的高亮文字，右键选择 **撤销高亮并移除重点**。编辑视图也可把光标放在高亮内，执行同名命令。
- **阅读视图：** 在课本或重点笔记中执行 **撤销高亮并移除重点**，或点击重点笔记上方的 **更多 → 移除收录…**，勾选条目后确认移除。
- **批量撤销：** 在 **移除收录** 中选择“全部章节”，允许同时移除不同章节的条目。确认窗口会说明条目数量及影响范围。
- **误操作恢复：** 在继续编辑前执行 **恢复上次撤销**，或在 **收录与整理面板** 中点击同名按钮。仅保存最近一次撤销记录，重新启动后仍可恢复。

撤销保留原文字，移除高亮、旁边的「重点」链接和对应收录条目；条目内的手写说明也会一起移除，可随最近一次撤销恢复。分组标题、分组说明及其他条目保留。原文块定位标识保留，以免影响其他链接。

恢复要求两篇笔记自撤销后没有其他修改；若已有修改，会停止恢复，避免覆盖新内容。普通编辑器的撤销只作用于当前笔记，不能代替插件的双向撤销。

已有 Canvas 卡片不会随撤销删除，其条目链接可能失效。可手动删除卡片，或使用 **另存完整思维导图** 生成最新结构。

## 整理关键词与导图

重点笔记顶部提供 **整理重点、新增重点、思维导图、更多** 四个入口。前三项分别用于整理、补充内容和导出；“更多”提供返回原文、移除收录、恢复和检查绑定。

**手动增加重点：** 点击重点笔记上方的 **新增重点**，或执行 **手动增加重点** 命令，填写名称和 Markdown 正文，选择已有章节或新建“手写重点”章节。保存后可直接在重点笔记里继续书写、修改正文。手写重点不需要绑定原文高亮，也能生成导图；请保留内部区域标识和定位标识。

**题型与名称：** 在 **整理重点 → 重点管理** 展开对应重点，修改名称并勾选「名词解释、选择、简答、论述」的任意组合，点击 **保存修改**。分类显示在名称后，例如“细胞结构（名词解释、简答）”，也可以全部取消。手写重点也可以在创建时选择题型。

**勾选内容创建导图：** 进入 **思维导图 → 新建导图 → 选择内容…**，或执行 **勾选内容创建导图** 命令，可跨章节勾选重点和关键词。勾选重点会包含其全部关键词；单独勾选关键词只包含该词及必要的所属重点、章节。每次创建新文件，不覆盖已有导图。此类导图会记住勾选范围，后续增补也沿用该范围（被勾选重点中新加入的关键词会一并增补）。

在 **整理重点 → 关键词归组** 中，先选择章节并勾选关键词，再点击 **创建重点…** 或 **加入已有重点…**；已有重点中的关键词可用 **移出重点**。需要重命名、修改题型或解散重点时，切换到 **重点管理**，展开对应重点即可。每条关键词同时只属于一个重点，不支持跨章节归类。解散前需要确认，解散后保留关键词、原标题和手写说明。

点击 **思维导图**，在“新建导图”中选择 **全部内容** 或 **选择内容…**。存在已有导图时，下方会出现“增补已有导图”，选择目标后点击 **增补这份导图**。已有导图列表包含本篇重点笔记生成的各个版本；文件丢失时仍可新建。新建时会在重点笔记旁自动创建 `思维导图` 文件夹，重名时自动编号，不覆盖旧文件。导图按「课本 → 章节 → 重点组 → 关键词」生成原生 Canvas，可自行改字、移动和修改连线。增补前请先关闭所选导图的标签页，确保手动编辑已保存。

导图按「章节 → 命名重点 → 关键词」显示分支。将已导出的关键词归为重点后，再次增补会新增重点节点，并更新这些关键词的父分支连线。已有卡片文字和位置保留，已删除的卡片不会恢复；未发生分组变化的连线保持不变。如需让最新名称和完整树形布局一起更新，可选择 **新建完整思维导图** 或 **另存完整思维导图**；以后仍可选择任一已有版本增补。

**自定义关键词：** 在 **整理重点 → 关键词归组** 的关键词列表下方输入文本，点击 **添加关键词** 或按回车。新关键词保存到当前章节并自动勾选，原有选择保留；没有章节时会自动建立“自定义关键词”章节。它与收录关键词一样可以创建或加入重点、移出重点、勾选生成导图及后续增补，也可在重点笔记中继续编辑内容。自定义关键词不附带原文链接，移除时不会修改原文，并支持“恢复上次撤销”。

**分组顺序：** 从未分组关键词创建重点时，新重点放在最早选中关键词的位置，组内关键词保留原有先后顺序，其他条目不重新排序。从已有重点中抽取关键词创建新重点时，新重点放在原重点之后。加入已有重点时，原本就在该重点内的关键词不会被重复移动。

## 编辑与异常处理

- 重点笔记是普通 Markdown，可直接补充解释。条目说明写在条目内容后、结束标识前；源码模式可查看这些标识。不要手动删除 `hc` 注释或 `^hc-...` 定位标识，删除条目请使用插件撤销功能。
- 收录保存文字快照。仅手动取消原文的 `==` 高亮，不会删除重点笔记中的条目。
- 用 Obsidian 自带操作改名或移动文件，插件会维护绑定和生成链接。
- 写入中断后执行 **恢复未完成收录并检查绑定**，或重新启用插件；该操作也会恢复未完成的撤销。
- 目标笔记缺失时，先恢复文件，或用 **绑定重点笔记** 重新选择包含原收录标识的笔记。标识损坏时可通过 Obsidian「文件恢复」还原后重试。
- 备份时保留笔记、Canvas 和插件的 `data.json`，其中包含绑定及恢复记录。
